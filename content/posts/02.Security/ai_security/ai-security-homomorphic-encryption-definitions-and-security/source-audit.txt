보정·명확화
1. 원문의 암호화·복호화 인수 순서는 키 아래첨자로 통일했다. 알고리즘의 의미는 같다.
2. 입력 메시지 개수는 t로 표기해 앞 글의 격자 차원 n 및 다항식 차원 N과 구별했다.
3. Eval 입력에는 f를 명시했다. 원문 19쪽의 후속 설명과 20쪽의 식을 반영했다.
4. Eval에서 사용할 pk와 evk를 둘 다 공개 입력으로 표시했다. pk를 evk에 포함하거나 암묵적으로 두는 표기와 구별했다.
5. PPT의 실행 시간은 보안 매개변수뿐 아니라 처리할 입력·회로 크기도 반영한다.
6. 일반 HE가 지원하는 함수 가족과 모든 다항 크기 회로를 지원하는 FHE를 구별했다.
7. ADD 전용은 PHE의 예일 뿐, PHE가 ADD만을 뜻하지는 않는다.
8. f(x)=2x의 곱셈 반례는 모든 a,b에서 두 값이 다르다는 주장이 아니다. 모든 a,b에서 같다는 조건이 실패함을 a=b=1로 검산했다.
9. 지수함수의 공역은 R_{>0}로 명확히 썼다. 덧셈군→양의 실수 곱셈군으로 해석할 수 있다.
10. Enc의 난수를 r,r′로 드러냈다. 다른 난수가 반드시 다른 암호문을 만든다고 주장하지 않았다.
11. 암호문 비트열의 equality, 복호화 결과의 equality, 암호문 분포의 equality는 서로 다른 조건이다.
12. 결정적 PKE의 구별 공격에는 정상 복호화 조건을 명시했다. 오류를 허용하는 경우에도 성공 확률이 1에 가깝다는 범위로 설명했다.
13. 평문 연산은 해당 평문 공간의 연산이다. 정수 결과와 법 연산의 결과를 구별했다.
14. 정확성 확률이 어떤 난수에 대해 취해지는지 밝혔다.
15. 정확형 HE의 실패 확률과 이후 근사형 HE의 수치 오차 허용은 구별했다.
16. IND-CPA 후보 메시지의 같은 길이 조건을 보충했다. m0≠m1은 표준 실험의 필수 문법 조건은 아니지만 원문의 구별 공격에서 유지했다.
17. 공개키 암호에서는 공격자가 Enc를 직접 실행하므로 동일 기능의 암호화 오라클을 별도로 줄 필요가 없다.
18. advantage는 |Pr[win]-1/2|로 정의했다. 원문의 상한 정의와 모든 PPT 공격자의 출력 뒤집기로 연결했다.
19. Enc(m0)≈_c Enc(m1)는 공개키와 공격자의 상태·적응적 메시지 선택을 포함한 게임의 축약 표기다.
20. pk만 제공하는 PKE의 안전성과 (pk,evk)를 제공하는 HE의 안전성을 구별했다. 원문의 무조건적인 underlying PKE+Eval 설명에 필요한 전제를 넣었다.
21. 공개정보 전체의 안전성을 가정한 뒤에만 public Eval의 시뮬레이션 환원을 제시했다.
22. 비밀키 의존 평가키의 공개는 별도 증명 대상이며, 표준 IND-CPA가 일반적인 KDM/순환 보안을 자동으로 함의하지 않는다.
23. 모든 HE가 같은 순환 보안 가정을 사용한다고 주장하지 않았다.
24. 제곱 Eval은 f_sq(x)=x²로 써서 한 입력 표기와 두 암호문 곱셈 표기를 연결했다.
25. IND-CPA 실험 밖에서 복호화 정보가 노출되는 모델은 이 논증의 자동 적용 범위로 두지 않았다.
26. 동형 정확성은 정직한 평가의 요구다. 부정한 서버의 계산을 검증한다는 보장은 별도다.
27. 강의의 Ring-LWE→leveled HE→bootstrapping→FHE 흐름은 모든 HE 구성을 분류하는 보편적 필수 단계가 아니다.
28. 회로 크기·깊이·곱셈 깊이를 구별했다.
29. compactness는 원문에 없는 보충이다. 정확성만으로 계산을 사용자에게 미루는 퇴화한 방식을 배제하지 못한다는 이유를 설명했다.
30. FHE에서 평가 시간의 회로 크기 의존과 결과 크기·복호화 비용의 회로 크기 독립을 구별했다.
31. Bootstrapping의 동형 복호화는 평문 또는 비밀키를 서버에 직접 제공하는 절차가 아니다. 필요한 평가 능력·오차·공개 보조 정보의 안전성 조건을 함께 적었다.

원문 외 추가 예제·설명
- Z_17에서 12+9≡4, 12×9≡6을 계산해 평문 공간의 연산 의미를 설명.
- f(x)=2x의 곱셈 보존 실패를 a=b=1로 검산.
- 결정적 공개키 암호의 직접 비교 공격을 원문의 한 문장 설명에서 전개.
- λ^-100은 negligible하지 않다는 역다항식 예제.
- 공개 Eval을 사용하는 공격을 공개정보 전체의 IND-CPA 실험에서 재현하는 환원.
- 제곱 예제의 m0=2,m1=3과 출력 후보 4,9.
- pk와 evk의 공동 공개, 키 의존 메시지·순환 보안의 전제 구분.
- 근사 수치 오차와 복호화 실패, 복호화 결과 노출, 부정한 평가의 검증 범위 구분.
- compactness와 회로·암호문을 묶어 반환하는 퇴화한 방식.
