수식·필기를 옮기며 바로잡거나 구별한 부분
- 31번 위쪽 식의 합 상한 d와 고정 RowRot 인자 1을 아래의 항등식 및 성분 증명에 맞춰 고쳤다.
  올바른 식은 k=0..d-1의 RowRot(U,k) odot ColRot(V,k) 합이다.
- 33번 R_-k의 끝 좌표 (d-k,d-d-1)는 유효한 끝 열을 지정하지 못한다.
  성분 인덱스와 1차 논문을 대조해 (d-k,d-1)로 바로잡았다. 고친 사실을 본문에 표시했다.
- 첫 내적의 마지막 값은 1300이다. 손글씨 숫자를 불명확하게 추측해 1600으로 옮기지 않았다.
  원본 B의 첫 열을 기준으로 수식·값을 모두 새로 검산했다.
- RowRot의 입력이 원본 A인지 재배치 U인지 명시했다. phi(A)의 두 번째 행 6,7,8,5를
  phi(U)의 두 번째 행 7,8,5,6과 섞지 않았다. 손글씨의 작고 모호한 라벨은 임의로 문장화하지 않았다.
- 회색 칸은 배치 유도 중의 빈칸이다. 입력을 0으로 지우는 알고리즘으로 바꾸지 않았다.
- 모든 행렬 인덱스는 mod d, 전체 슬롯 회전은 mod n이다. 두 주기를 구별했다.
- 기본 모형 n=d²와 CKKS의 n=N/2를 명시했다. 모든 n>=d²에서 같은 경계 회전이 된다고 쓰지 않았다.
- 단순 슬롯 뒤 0 패딩의 반례, 같은 행렬의 반복 블록, 행렬 차원의 0 패딩을 구별했다.
- 서로 다른 행렬을 연속 블록에 놓고 같은 공식이 독립적으로 작동한다고 주장하지 않았다.
- 마스크의 평문 곱과 두 암호문의 곱을 구별했다. 공개 마스크에는 입력 원소가 없다.
- 암호문 곱의 세 성분과 재선형화를 구별했다. raw 곱 자체와 키 전환을 같은 단일 연산으로 쓰지 않았다.
- d개 병렬 암호문 곱의 깊이 1과 앞선 평문 마스크 단계·스케일·법 체인의 소비를 구별했다.
- 원문의 근사 회전 수와 실제 작은 블록 구성의 정수 횟수를 구별했다. 최적 하한·실측 성능으로 제시하지 않았다.
- 1차 논문의 sigma BSGS 계수 3sqrt(d)와 이번 강의의 2sqrt(2d)를 구별했다.
  강의의 계수는 길이 2d-1 구간을 약 sqrt(2d)로 묶는 본문 보충식으로 설명했다.

원문 외 추가 설명
- 네 순열 항등식의 모든 성분에 대한 증명. k→(i+j+k) mod d가 전단사임을 사용했다.
- 원문 4×4 예제의 전체 출력 16개, 네 출력 위치의 항별 값, 직접 회전·마스크 구현의 검산.
- 일반 k의 phi^k를 두 직접 회전으로 만드는 구성. 평문 곱을 k단계 누적하지 않아도 됨.
- 음수 시작점과 간격 d를 포함한 유한 구간 BSGS 항등식, 마지막 부분 블록의 0 마스크.
- d=4의 sigma b=3, tau b=2인 실제 회전 일정, 합계 15회.
- d=16과 64의 구체적인 블록 선택과 회전 수 61,225.
- 암호문·암호문 곱 d회, 마지막 합 d-1회. 재배치 안의 평문 곱·덧셈은 별도.
- 선형 마스크 곱 후 스케일 정렬과 raw 곱의 ΔUΔV, rescale 후 ΔUΔV/q_ell.
- 남는 슬롯의 같은 데이터 반복과 3×3→4×4 행·열 확장 조건.
