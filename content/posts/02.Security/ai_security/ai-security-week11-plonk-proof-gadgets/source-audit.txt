보충·정확성 조건
- ZeroTest에서 강의의 허용 차수 deg q <= d와 정직한 몫의 deg q <= d-k를 구별. 강의 규칙의 오류는 (d+k)/p <= 2d/p.
- ProdCheck는 강의 표기의 t(1)=f(1), t(omega^(k-1))=1을 유지. t(1)=1 관례를 섞지 않음.
- 보간으로 deg t < k가 가능하지만 강의 허용 한계 <= k에 맞춰 오류를 분석.
- f,t,q의 사전 고정 순서와 실제 PCS opening 증명의 필요성 명시.
- t=0 반례로 경계 조건의 필요성을 설명.
- f=g=0,t=1 반례로 분모를 곱한 식만으로 원래 비율을 정의할 수 없음을 설명.
- NTT O(k log k)는 d=O(k)인 설정의 비용임을 명시. 일반 d 비용으로 과장하지 않음.
- permutation의 두 challenge 순서는 f,g 고정 → beta → t,q 고정 → 평가점 r.
- permutation의 여섯 질의는 t(last),t(r),t(omega r),q(r),f(omega r),g(omega r).
- monic 다항식 차이의 (k-1)/p 상한은 비교 단계만의 보충 분석. 분모가 0인 예외와 ProdCheck의 오류를 포함한 최종 상한으로 주장하지 않음.
- F17 ZeroTest f=3(X^4-1),r=2 예제와 정확성 반례는 직접 추가한 보충.
