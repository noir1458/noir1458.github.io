원문과 보충 구분 및 교정
- 4KiB 페이지, 64B struct page, 5단계 주소는 강의 예제 조건으로 명시.
- phys addr를 포인터로 캐스팅하는 것과 direct-map 접근을 구별.
- 9비트 5개 + offset 12비트. 자료 8쪽의 offset+flags 표기는 VA offset과 PTE flags로 구별.
- 페이지 테이블 순서는 PGD/P4D/PUD/PMD/PTE. 자료 12-13쪽 도식의 PUD/PMD 순서 표기를 수정.
- XArray 64슬롯의 마지막 인덱스는 63. 실습 9쪽 그림의 slots[64] 오기 명시.
- 최초 항목 직접 저장은 index 0 조건. 모든 최초 인덱스로 일반화하지 않음.
- xa_node의 count는 하위 전체 객체 개수가 아니라 그 노드의 non-NULL 슬롯 수.
- ds_monitoring은 수업 예제. 동시 최초 삽입/할당 실패/수명 문제를 별도 설명.
- CPU 호출 비율과 CPU 사용 시간 비율을 구별.
- 실습 47쪽 출력 수치: 839701 + 854459 + 641532 + 810036 = 3145728.
  정수 비율 합 98%는 절삭 결과. 합계 일치는 일반적 동시성 안전성의 증거로 쓰지 않음.
- 설명용 fio 규모 계산은 수행 결과로 표현하지 않음.
- 강의 원본 전체 이미지와 파일은 새 글에 재배포하지 않음. 문장과 표/텍스트 도식으로 재구성.
